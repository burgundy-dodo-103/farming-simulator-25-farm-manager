# Farming Simulator 25 Farm Manager — feature reference

A farm manager workspace for Farming Simulator 25, built around vehicle categories and project notes, with session planning kept in a separate reference area.

| Section | Description |
|---|---|
| Vehicle categories | A dedicated section for vehicle categories and the configuration details associated with that area. |
| Project notes | A dedicated section for project notes and the configuration details associated with that area. |
| Session planning | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
